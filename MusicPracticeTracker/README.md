
# Music Practice Goal and Repertoire Tracker

## Project Information
- Course: CAP455 - Object Oriented Programming Using C++
- Language: C++
- Application: Console-based
- Status: CA1 - Design and Create

## Problem Statement
Musicians need a simple way to manage practice goals,
track musical pieces they are learning, and record
their practice activities.

## Planned Features
- Create and view practice goals
- Manage musical repertoire
- Record practice sessions
- Search and update records
- Save data to files
- Generate practice progress reports

## Repository Structure
- docs/: Proposal and design documents
- src/: C++ source code
- data/: Sample data files
- tests/: Test cases and evidence

## Build and Run
Build and run instructions will be added
after the first C++ program is implemented.

## Development Phases
- CA1: Design and in-memory Create/Read
- CA2: File persistence and search/update
- CA3: Inheritance, polymorphism and safe deletion
- CA4: Full CRUD, exceptions, templates and STL
